YatraSuite
===

The ```microservice``` for travelling management.


## Services

---

```
    /
    ├── common-service
    ├── ride-service
    ├── user-service
    ├── vehicle-service

    ├── yatra-webapp

```

### API Calls

- Get All Records

```shell
curl http://localhost:8080/api/v1/yatrasuite
```

- Filter by ID

```shell
curl http://localhost:8080/api/v1/yatrasuite/2
```
